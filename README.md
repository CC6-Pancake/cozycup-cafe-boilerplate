# CozyCup Cafe ☕

Welcome to the CozyCup Cafe website!

## About the Project

CozyCup Cafe is a simple cafe website designed to provide customers with information about our coffee, desserts, and cafe.

## Features

- Home section
- Navigation bar
- Cafe menu
- About Us section
- Contact information
- Responsive design
